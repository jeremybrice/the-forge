Roadmap enhancements

The Forge Shell Roadmap page is now an interactive planning surface. You can change status, reschedule work by dragging cards, inspect details, jump into Product Forge, scan a dense table, and keep your view preferences across sessions.

Forge Shell · Roadmap Product Forge cards Shipped 2026-07

Overview

Roadmap visualizes Product Forge initiative cards across time using releases defined in project config (cards/roadmap.md). It is still a planning surface—not a full card editor. Use it for schedule, status, and triage; open Product Forge for deep editing.

Prerequisite

Your project needs a cards/ directory with Product Forge cards. Open the project folder in Forge Shell, then select Roadmap in the sidebar.

Open Roadmap

  1. Launch Forge Shell (desktop app or browser/server mode).
  2. Select your project folder (must include cards/).
  3. In the left sidebar, choose Roadmap (road icon).

If no cards/ folder exists, Roadmap shows a “not active” message until Product Forge cards are present.

Change status

Status is no longer display-only. On Card (and Table) view, click the status pill on a card:

Notification system overhaul
Approved ⋯
  1. Click the colored status (dot + label) on an initiative, epic, or story.
  2. Choose a new status from the menu (options depend on card type).
  3. The pill updates immediately and is written to the card file on disk.
  • Choosing the same status closes the menu without writing.
  • Press Esc to close the menu.
  • If a card has an unusual status from another tool, it still displays; picking a menu option replaces it.
Note

Timeline bars show status as a color cue; use Card or Table view (or the drawer / quick-assign menu) to change it.

Schedule with drag & drop

In Card view, initiative cards can be dragged between period columns and the Unscheduled column. This assigns or clears the card’s release field—it does not invent free-form dates.

  1. Ensure releases exist under Settings → Releases (name + start/end dates).
  2. Drag an initiative onto a quarter/month column whose dates overlap a release.
  3. Or drag to Unscheduled to clear the schedule.

What to expect

SituationResult
One release covers that period Card is assigned that release name.
Several releases overlap the period A small picker asks which release to use.
No release covers the period Error toast; nothing is written. Add a release in Settings first.
Drop on Unscheduled Release is cleared; card appears under Unscheduled.
Release spans multiple quarters Card may appear in more than one column—that is expected.
Important

Only initiatives are schedule units for column placement. Epics and stories nest under their initiative; drag does not reparent them. To change hierarchy, use Product Forge.

Detail drawer

Click a card’s body (not the status pill or ⋯) to open a summary drawer on the right.

  1. Click an initiative (or epic) title area in Card or Table view, or a bar/label in Timeline.
  2. Review type, status, product/client/module, release dates, hierarchy, and a short description.
  3. Click Open in Product Forge to jump to the full card and edit there.
  4. Press Esc (or the drawer close control) to dismiss.
  • Opening the drawer closes the filter panel (and vice versa).
  • You can still change status from the drawer when a status control is shown.
  • If Product Forge is hidden in plugin visibility, you’ll get an error toast and stay on Roadmap.

Quick-assign menu

Use the ⋯ button on a card, or right-click the card, for planning actions:

ActionEffect
Set release…Assign a release from your Settings list.
Clear scheduleRemove release (Unscheduled).
Add to / remove from bucketGroup initiatives under colored bucket labels (config in Settings).
Change status…Same type-aware status options as the status pill.
Open in Product ForgeDeep-link to the card editor.

Press Esc or click outside to close the menu. Drag still works on the card body; start a drag from the card, not the ⋯ control.

Table view

Choose Table in the view toggle for a dense, sortable list of initiatives.

  1. Click a column header (Title, Status, Product, Release, Period, Epics, …) to sort; click again to reverse.
  2. Use the same filter panel as Card/Timeline—filters apply to all views.
  3. Click a row to open the detail drawer; use the status cell to change status without leaving the table.
Tip

Table is best for scanning large portfolios. Use Card for drag-and-drop planning, Timeline for duration at a glance.

Saved preferences

Your toolbar choices are written to cards/roadmap.md (shared across desktop and browser modes for that project):

  • Default view (Card / Timeline / Table)
  • Time granularity (quarterly / monthly)
  • Current year
  • Show stories on/off

Saves are debounced and usually silent on success. Change a control, wait about a second, then reload—your choices should restore.

Settings (releases & buckets)

Open the gear icon for roadmap configuration:

  • Releases — name, start date, end date. Cards schedule by matching the card’s release name to these ranges.
  • Buckets — named colored groups of initiatives for Card view organization (optional).
  • Swim lanes — which products appear as lanes in Timeline view.
Before you drag

Define at least one release that covers the periods you plan to use. Without releases, everything stays Unscheduled.

Filters

Open the filter control to narrow by product, client, module, status, or release. Active filters show a count badge. Clear all from the filter panel footer. Filters apply across Card, Timeline, and Table for the current session.

How scheduling works

Keep this mental model in mind:

  1. Settings defines named releases with date ranges.
  2. An initiative’s markdown frontmatter has a release field (the release name).
  3. Roadmap places the initiative in any period that overlaps that release’s dates.
  4. Dragging or quick-assign changes the name on the card—not the release calendar itself.

Editing a release’s start/end in Settings can move all cards on that release across columns. That is intentional: the calendar is shared configuration.

Tips & troubleshooting

IssueWhat to try
Drop does nothing / error toast Add a release in Settings whose dates cover that period.
Card appears in two quarters Its release spans both periods—expected. Narrow the release dates or accept multi-period placement.
Can’t drag an epic Only initiatives are draggable for schedule. Change epic status via the pill or ⋯ menu.
Open in Product Forge fails Ensure Product Forge is visible for the project and the card file still exists under cards/.
View didn’t stick after reload Wait a moment after toggling (debounced save), then reload. Confirm you have write access to the project folder.
Stale data Roadmap auto-refreshes about every 5 seconds; use the refresh control if needed.
Keyboard

Esc closes the topmost UI layer in order: status/quick menu → Settings modal → detail drawer → filter panel.

Quick checklist (first 5 minutes)

  1. Open Roadmap and confirm Card / Timeline / Table all open.
  2. In Settings, add or verify a release for the current year.
  3. Drag one Unscheduled initiative onto a period—confirm it sticks after refresh.
  4. Change its status from the pill; open the drawer; use Open in Product Forge.
  5. Try Table sort + a filter; switch year and reload to confirm prefs save.
